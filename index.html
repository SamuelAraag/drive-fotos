          Sair e apagar o token?

          O token e as fotos guardadas somem deste navegador, e o GitHub não mostra o token de novo. Se você não tiver ele guardado, vai precisar gerar outro para entrar.

          Entrar no Drive Fotos

          As fotos ficam num repositório privado do GitHub. Gere um token só para ele, na conta dona do repositório:

          1. GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens.
          2. Generate new token, com acesso só ao repositório .
          3. Permissão Contents: Read and write.

          O token fica guardado só neste navegador.
