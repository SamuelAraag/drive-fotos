              Sair e apagar o token?

              O token e as fotos guardadas somem deste navegador, e o GitHub não mostra o token de novo. Se você não tiver ele guardado, vai precisar gerar outro para entrar.

              Entrar no Drive Fotos

              As fotos ficam num repositório privado da sua conta do GitHub. Antes de entrar:

              1. Crie um repositório privado chamado , marcando Add a README.
              2. GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens.
              3. Generate new token, com acesso só ao repositório .
              4. Permissão Contents: Read and write.

              O token fica guardado só neste navegador.
